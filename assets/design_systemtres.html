05 / Animation

System Motion

01

Scroll Reveal

Class: .reveal
Behavior: Elements slide up 2rem and fade from 0 to 1 opacity using a custom cubic-bezier ease out curve on intersection.

02

Staggered Entry

Class: .delay-[ms]
Behavior: Delays the reveal transition by 100, 200, 300, 500, or 700ms to create sequential loading patterns.

03

Text Mask Reveal

Class: .text-reveal-content
Behavior: Wraps text in an overflow-hidden container, translating the text from 110% Y to 0 for a sharp, masked reveal effect.
